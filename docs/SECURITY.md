# Security & Compliance Architecture

## 1. Authentication & Session Security
- JWT authentication with salt-hashed passwords via `bcryptjs`.
- HTTP Bearer tokens for all protected API routes.

## 2. Secrets Management
- Meta Permanent Access Tokens, WABA IDs, App Secrets, and Database Connection Strings are kept strictly on the backend.
- Token values are masked when queried by the frontend.

## 3. Webhook Signature Validation
- Webhooks validate `X-Hub-Signature-256` HMAC SHA-256 signatures generated by Meta using your App Secret.

## 4. Input Sanitization & Protection
- Parameterized PostgreSQL SQL queries prevent SQL injection.
- CSV import values strip leading formula characters (`=`, `@`, `+`, `-`) to prevent CSV injection.
- File uploads are capped at 10MB limit.
